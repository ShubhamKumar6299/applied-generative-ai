# Generative AI - Applications and Tools

## Applications of Generative AI

Generative AI is widely used across multiple domains:

* IT and DevOps
* Entertainment
* Finance
* Healthcare
* Human Resources

It is transforming workflows by improving efficiency and enabling automation in day-to-day tasks.

---

## Text Generation

Generative AI can produce and manipulate text, including:

* Answering questions
* Generating content
* Language translation

### Common Tools

* ChatGPT (OpenAI)
* Gemini (Google)

**ChatGPT:**

* Supports text, image, and voice interactions
* Strong in step-by-step explanations
* Useful for research and creative tasks

**Gemini:**

* Handles long documents effectively
* Supports multimodal inputs (text, image, voice)
* Integrates well with Google ecosystem

---

## Image Generation

Generative AI can create and modify images using prompts.

### Capabilities

* Text-to-image generation
* Image-to-image transformation
* Style transfer
* Inpainting and outpainting

### Models

* DALL·E
* Stable Diffusion
* StyleGAN

### Tools

* Bing Image Creator (Microsoft)
* Adobe Firefly

## Code Generation

Generative AI can assist in software development by:

* Generating new code
* Optimizing existing code
* Converting code between languages

### Tools

* GPT-based models
* GitHub Copilot
* PolyCoder
* IBM Watson

**Note:**
These tools are powerful but limited by their training data and may require human validation.

---

## Generative AI vs Agentic AI

### Generative AI

* Reactive in nature
* Works based on prompts
* Input → Output generation

---

### Agentic AI

* Proactive and goal-driven
* Uses reasoning to perform tasks
* Follows a multi-step process:

1. Perceive
2. Decide
3. Execute
4. Learn (feedback loop)

Agentic AI leverages LLMs to break complex problems into smaller steps using **chain-of-thought reasoning**.

---

## Key Takeaway

Generative AI focuses on content creation, while Agentic AI extends this capability by enabling systems to take actions, make decisions, and iteratively improve toward a goal.
